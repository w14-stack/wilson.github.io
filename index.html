About

01 — background

I study electrical and electronics engineering, power option, working through coursework spanning electrical machines, power generation, microprocessor architecture, and digital logic design. That grounding in signals, systems, and hardware constraints carries directly into how I approach my other focus.

Alongside my studies, I work as a quantitative researcher on WorldQuant BRAIN, building and documenting alpha expressions, composite factor frameworks, and LLM-assisted research tooling. I treat both disciplines the same way: understand the underlying system, instrument it carefully, and validate before trusting the output.

alpha-harness

Alpha Harness

A local research console for WorldQuant BRAIN — a FastAPI/uv backend paired with a Vite/pnpm React frontend, authenticated against a BRAIN account, built to make alpha iteration and data exploration faster than working through BRAIN's web UI alone.

composite-alpha
Python · pandas
numpy

Composite Alpha Framework

A reusable Python framework for combining multiple alpha signals through cross-sectional z-scoring and winsorization, with IC and IR validation built in to check each candidate factor before it's trusted in a larger composite.

AI-Assisted Alpha Generation

A notebook-based pipeline that turns a written hypothesis into a structured alpha expression via an LLM, then hands it off to BRAIN's simulation tooling to generate settings and run the resulting candidates in batch.
